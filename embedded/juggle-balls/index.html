Prototype

Smart Juggle Balls

Juggling balls that share a BLE clock, time throws together, flash in sync, and find the music’s BPM with an FFT.

Prototype 3 balls in the sync run BLE + IMU
Reported results only. Figures below are the bench results already in hand. Targets are labeled as targets. Anything this page does not state is TBD — no extra specs, prices, or results.

Light-function scheduler

Next: a library of parametric light functions driven by the shared global clock, with scheduled broadcasts so a late command still lands in sync. Target command latency is about 0.25 s. That latency is a target, not a result.

hallow-deck

Tie-in: live ball data drives virtual balls in the hallow-deck XR project. A ball view in this repo is TBD.

Achieved

  • BLE clock sync to about 10 µs on the raw BLE stack, while streaming roughly 25 Hz IMU data from 3 balls.
  • Throw timing is solid.
  • Synchronized flashing is solid.
  • Siteswap pattern detection after 3–4 throws, about 3 s behind.
  • An FFT picks the music’s BPM without being told the tempo.

In progress

Throw height, by integrating the IMU data. No error figure yet — TBD.
