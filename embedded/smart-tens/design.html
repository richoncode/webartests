Project design

Smart TENS

Multi-electrode sensing and stimulation for large leg muscles (quads, hamstrings, calves): monitor EMG, flag outlier / cramp-like patterns, and optionally apply TENS to help the muscle leave a cramp state toward relaxation.

Status: design Phase 0 → 3 EMG + TENS DIY experimental
Not a medical device. This document is an engineering design for a personal prototype. Electrical stimulation can be harmful. Do not use on the chest, neck, head, or across the heart; do not use with a pacemaker / implanted stimulator, pregnancy, open wounds, or impaired sensation without clinician guidance. Keep stimulation current-limited, isolated, and under a dead-man / intentional enable. Treat all numbers below as starting points to validate on the bench with a series resistor / dummy load — never “tune on skin” first.
Goals · Modes · Architecture · Schematics · Software · Plan · BOM · Open questions

Goals

  1. Sense EMG from multiple sites on large leg muscles (target: 4–8 differential channels + shared reference / bias).
  2. Track per-channel baselines (quiet / voluntary contract / walk) and detect outlier patterns consistent with cramp (sustained high amplitude, tremor-band energy, asymmetry vs contralateral).
  3. Actuate (TENS mode) biphasic constant-current pulses on selected electrode pairs to interrupt cramp / encourage relaxation, with hard safety limits.
  4. Log & review waveforms, detections, and stim events on phone/laptop for tuning thresholds.

Operating modes

Monitor

Continuous EMG acquisition. Streaming feature vector (RMS, MAV, zero-crossings, 40–80 Hz band power). Outlier score vs rolling personal baseline. No HV stim rail enabled.

TENS

User- or rule-armed. Mux disconnects sense path on active stim channels (or uses dedicated stim electrodes). Constant-current biphasic pulses; intensity ramp; auto-stop on timeout / release / EMG drop.

Sense / stim isolation rule: never drive TENS into an active EMG front-end input. Phase 1 uses separate stim electrode pairs. Phase 2 may share sites via analog mux with make-before-break protection and input clamps.

Firmware (MCU)

  • Sample EMG @ 1–2 kHz/ch; DMA into ring buffers.
  • Per 100–200 ms window: RMS, MAV, dominant band energy, contralateral ratio if available.
  • Personal baseline: EWMA of quiet + activity modes; outlier = persistent z-score / Hotelling-style score.
  • TENS ISR: charge-balanced biphasic timing; ramp; hard session timer; kill on button release.
  • BLE GATT: stream compressed features + optional raw snippets; log stim events.

Host app

  • Live strip charts per channel; outlier badges; arm / intensity UI with deliberate confirms.
  • Session export (CSV/Parquet) for tuning thresholds offline.
  • Later: on-device TinyML classifier once labeled cramp sessions exist.

Open questions

  • Shared vs dedicated stim electrodes (complexity vs comfort)?
  • On-leg wearable vs bedside “cramp kit” you grab when it hits?
  • Regulatory posture: personal research only vs eventual FDA path (assume personal for now)?
