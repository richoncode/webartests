  <h3>Switch sequence (firmware + hardware)</h3>
  <div class="schematic-frame" id="switch-seq">
    <ol class="seq-steps">
      <li><strong>MONITOR (default)</strong> — SEL = SENSE; pads connected to AFE; stim path open; EMG samples flow.</li>
      <li><strong>Blank</strong> — MCU blanks ADC / holds last sample; stim EN stays off.</li>
      <li><strong>OPEN (break-before-make)</strong> — both throws open for 50–200&nbsp;µs; AFE inputs quieted to REF.</li>
      <li><strong>STIM</strong> — SEL = STIM; pads to isolated H-bridge; sense path open behind clamps; EN on only with dead-man.</li>
      <li><strong>Pulses</strong> — biphasic constant-current on shared pads; AFE sees clamps only.</li>
      <li><strong>Return</strong> — EN off, wait discharge; SEL = OPEN; SEL = SENSE; unblank after settling / artifact window.</li>
    </ol>
    <p class="schematic-caption">Fig. 4 — Shared-pad switch sequence (same states as the former Mermaid diagram; HTML so it cannot fail to render).</p>
  </div>

  <h3>Hard rules for shared pads</h3>
  <ul>
    <li><strong>Break-before-make only</strong> — never a make-before-break mux; mid-state must disconnect stim before sense reconnects.</li>
    <li><strong>AFE never sees compliance voltage</strong> — when SEL=STIM, sense throw is open and AFE pins sit behind rail clamps + series R (and optionally a short across IN+/IN− through a quieting resistor to REF).</li>
    <li><strong>Stim enable is gated</strong> — hardware AND: <code>SEL==STIM</code> ∧ <code>dead-man</code> ∧ <code>not FAULT</code>. Firmware alone is not enough.</li>
    <li><strong>Blanking window</strong> — discard EMG for the open gap + a post-stim artifact window (typically tens–hundreds of ms) before outlier logic resumes.</li>
    <li><strong>Switch rating</strong> — off isolation and voltage rating must exceed the stim open-circuit / compliance voltage (design for ≥2× expected peak).</li>
    <li><strong>Common REF</strong> — bias/reference electrode stays on a bony site and is <em>not</em> a stim return unless the topology is explicitly redesigned for that (default: REF is sense-only).</li>
    <li><strong>Lead-off / wet check</strong> — before enabling STIM, verify electrode impedance is in-range so you do not command high voltage into an open lead.</li>
  </ul>

  <div class="callout danger">
    <strong>Bench gate before skin:</strong> prove the mux on a resistive dummy load with a scope on the AFE input pins during STIM.
    Pass criterion: AFE input voltage stays within clamp limits for every pulse; no DC offset residual that rails the amp after return to SENSE.
  </div>
