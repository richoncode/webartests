How to read this

  • Particles are bytes moving memory → cache → compute. Density tracks achieved bandwidth (compressed scale, so slow chips are still visible).
  • Bright compute cells = busy. Dim amber cells + STALL = units waiting on memory. The bright inner square on Apple M5-generation cores is the Neural Accelerator.
  • Layer strip: each layer has an attention (top) and MLP (bottom) half, amber if memory-bound, green if compute-bound.
  • VAU Spec badges: verified vendor number, approximate/derived/third-party, or assumed. Click a badge for the source.
  • Range bar: blue = estimate range (efficiency ±20%), white = central estimate, dashed = peak-spec ceiling.
  • Apple memory blocks are scaled to bandwidth, not to a package count.
