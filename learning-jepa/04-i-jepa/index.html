Module 03: I-JEPA - The Genesis of Image Representation

First working implementation: I-JEPA learns by masking large chunks of an image and predicting their features.

Breaking the Generative Dependency

I-JEPA (Image-JEPA) avoids the heavy decoder of a Masked Autoencoder (MAE). Instead of reconstructing pixels, it predicts representations. The key is Multi-Block Masking: sampling large, semantic blocks rather than random pixels to force the model to learn high-level object features.

The "Secret Sauce": EMA Update

To prevent Representation Collapse, I-JEPA uses an asymmetric teacher-student setup. The student (context encoder) is updated via gradients, while the teacher (target encoder) is updated via an Exponential Moving Average (EMA).

# PyTorch Snippet: The EMA Update
@torch.no_grad()
def ema_update(self, momentum=0.996):
    for p_target, p_context in zip(self.target_encoder.parameters(), self.context_encoder.parameters()):
        p_target.data.mul_(momentum).add_(p_context.data, alpha=1.0 - momentum)
