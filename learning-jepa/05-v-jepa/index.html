Module 05: V-JEPA & MC-JEPA

Moving from Space to Time: Forcing models to learn persistence and dynamics by preventing "Temporal Cheating."

Spatiotemporal Dynamics

Predicting video is harder than predicting images because models can "cheat." If you mask random pixels in a video, the model doesn't need to understand motion; it can just look at the exact same pixel in the previous or next frame to find the answer.

**V-JEPA** solves this using Tubelet Masking: hiding the same spatial area across the entire temporal duration of the video block. This forces the model to learn World Physics—the understanding that an object continues to exist and follow a trajectory even when it is completely hidden.

In this mode, the moving object is never fully hidden. The model can simply 'see through' the noise by comparing adjacent frames. It learns to interpolate pixels, not to model the world.
