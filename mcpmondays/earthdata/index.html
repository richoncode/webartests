What it is

NASA’s Earth science catalog, as agent tools

The Earthdata MCP is NASA’s official hosted server for its Common Metadata Repository (CMR), the catalog behind Earthdata Search. An agent can turn a plain word into NASA’s controlled vocabulary, find the collections that match, and check that real files exist for a place and a day before anything is downloaded. The server’s own instructions call this Discover, then Verify, then Access.

Connect

One URL, no key

The endpoint is https://cmr.earthdata.nasa.gov/mcp/v1 over Streamable HTTP. The discovery tools work without an API key. In Cursor, add this to mcp.json:

mcp.json 
{"mcpServers":{"earthdata-mcp":{"url":"https://cmr.earthdata.nasa.gov/mcp/v1"}}}

Source and docs: github.com/nasa/earthdata-mcp.
