Connect

One URL, no key

Streamable HTTP, no token. Claude Code:

shell 
claude mcp add --transport http plateau https://api.plateauview.mlit.go.jp/mcp

In Cursor, add this to mcp.json:

mcp.json 
{
  "mcpServers": {
    "plateau": {
      "url": "https://api.plateauview.mlit.go.jp/mcp"
    }
  }
}

Docs: PLATEAU MCP server. Claude Desktop’s free plan does not speak HTTP MCP; the docs describe an adapter for that case. Cursor and Claude Code take the URL directly.

Flood view

A rank that is stored on the tile

On 12 November 2026 the LOD2 textured tiles for Chiyoda were checked directly, not from a side file. Each building’s batch table includes 隅田川・新河岸川流域（都道府県管理区間）_L2（想定最大規模）_浸水ランク. Around Tokyo Station the values are 0.5m未満, 0.5m以上3m未満, or empty. Flood view colors those strings. It does not estimate a depth.

The same tiles also store other hazard fields, including Kanda River ranks and the Tokyo storm-surge rank from the 19 December 2024 map. They do not match the Sumida rank building for building. Click a building to read whichever of them are filled in. The dataset notes say survey attributes can be missing or out of step with the footprint, and most buildings have no name.

Before you rely on it

Experimental, no SLA

The PLATEAU MCP server is a trial. MLIT states there is no availability or performance guarantee, tools and response shapes can change without notice, and production use is not recommended. Support is not promised.

Source: the project’s own overview.
