What you just watched

A plain request goes to an agent connected to the official Mapbox MCP server. The agent calls search_and_geocode_tool once for each place, then directions_tool with the two coordinates and any exclusions. The route then plays as a night chase-camera drive in the Mapbox Standard style, which includes lane markings, turn arrows, crosswalks and 3D buildings by default.

What is live and what is precomputed

precomputed The three preset drives were fetched at build time from the Mapbox Search Box and Directions APIs, which are the APIs those two tools wrap.

live A typed request calls the same two APIs from your browser: Search Box forward search for the place, with proximity set to the car's current position, then Directions from where the car is now. The cards show the tool names with the arguments actually used. The map, 3D city, lighting and camera are also rendered live by Mapbox GL JS.

not on this page No language model runs here. Typed text is parsed with simple rules: phrases like “take me to” are stripped, “from X to Y” sets both ends, and “avoiding motorways” or “no tolls” becomes the exclude value. In a real agent, the model reads your words and picks the tools and arguments itself. Long routes play back faster, and the HUD shows the speed-up.

Connect the server

Mapbox runs a hosted endpoint at https://mcp.mapbox.com/mcp, or you can run it locally with Node or Docker. Either way it needs a Mapbox access token (a free account works).

{
  "mcpServers": {
    "mapbox": {
      "command": "npx",
      "args": ["-y", "@mapbox/mcp-server"],
      "env": { "MAPBOX_ACCESS_TOKEN": "YOUR_TOKEN" }
    }
  }
}

Other tools in the server

Besides search and directions, it has reverse_geocode_tool, category_search_tool, place_details_tool, ground_location_tool, isochrone_tool, matrix_tool, optimization_tool, map_matching_tool, static_map_image_tool and render_map_tool, which draws results on a live map inside clients that support MCP Apps. A set of offline geometry tools (distance_tool, buffer_tool, bbox_tool and others) runs without calling any Mapbox API.
