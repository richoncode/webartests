Scenario

Made by Scenario MCP server

Scenario’s MCP server lets an AI agent generate images, video, 3D, and audio, train custom models, and search, organize, and manage assets and workflows through natural language.

It works from Claude, Cursor, VS Code, or any MCP client. That is the interesting part: the agent you already use for code can also make the pictures, clips, models, and sounds a project needs, then find them again later, without a separate trip through a creative app. Scenario builds and hosts the server. Connect

Cursor

Add this entry in Cursor’s MCP settings, or in an mcp.json file. The URL is Scenario’s Streamable HTTP endpoint. OAuth is the recommended sign-in and runs when you first use the server. An API key works instead, if you prefer that.

mcp.json 
{
  "mcpServers": {
    "scenario": {
      "url": "https://mcp.scenario.com/mcp"
    }
  }
}

Claude, VS Code, and any other MCP client can use this same endpoint with Streamable HTTP and OAuth (recommended) or an API key; a client that only speaks stdio can run npx mcp-remote@latest https://mcp.scenario.com/mcp.

Example prompts

Paste one of these to the agent after the server is connected. The first is Scenario’s own example. The others are the same kind of ask: a specific subject, materials, and how it should sit in the frame.

From Scenario’s site

Create a premium campaign image for orange headphones. An exploded view of the components, floating above a cobalt-blue plinth.

Game asset

Create a game inventory icon of a salvaged diving helmet: pitted copper, a cracked sea-green faceplate, and a coil of tarred rope, lit like a museum piece on wet dock planks.

3D prop

Create a 3D prop of a folding field lantern: brushed brass ribs, frosted glass panels, and a leather carry strap, shown half-open on a dark stone plinth.

Audio cue

Create a short audio cue of a lantern being lit in a quiet stone room: a thumb strike, a soft gas catch, then a low warm bloom that fades in under two seconds.

Custom model

Train a custom model on my ink-and-wash storyboard frames, then create a new panel of a courier crossing a rain-lit market, keeping that line weight, paper tone, and limited palette.
