Connect

One endpoint

The hosted server is huggingface.co/mcp. Open huggingface.co/settings/mcp while logged in, pick a client (Cursor, VS Code, Claude, and others), and paste the snippet that page generates. The docs say to use that page rather than writing config by hand. The public setup page’s OAuth URL is https://huggingface.co/mcp?login. Manual Cursor config with a read token:

mcp.json 
{
  "mcpServers": {
    "huggingface": {
      "url": "https://huggingface.co/mcp",
      "headers": {
        "Authorization": "Bearer <HF_TOKEN>"
      }
    }
  }
}

Replace <HF_TOKEN> with a Hugging Face read token. That manual block is the one shown on huggingface.co/mcp for Cursor.
