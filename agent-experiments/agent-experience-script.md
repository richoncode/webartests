# Narration Script — The Sport Agent Experience

A step-by-step walkthrough of the interactions between Richard, his personal
agent, and the specialist sports agent — focused on what each side does and
says, not on the interface.

---

**1. Intro**
This is a quick look at how two AI agents can work together to help you,
without either one needing to know everything about you. Richard has his own
personal agent, think of it as his assistant, and there's a separate sports
agent that specializes in tennis analysis. Richard asks his agent about the
Alcaraz match.

**2. Checks in**
Before jumping in, Richard's agent checks in with the sports agent, to see
what it can actually do.

**3. Introduces itself**
The sports agent introduces itself, and explains what to expect. It won't
keep any long-term records between conversations, but if it's ever given a
hint about what someone prefers, it's happy to use it.

**4. No memory yet**
So, since it's their first conversation, the user agent asks the question
with no user preferences attached.

**5. First answer**
The sports agent answers with the tactical breakdown Richard asked for. But
it does two more things. First, it suggests a couple of things about Richard
worth remembering for next time, like how much detail he prefers. And
separately, it offers a few topic ideas for what he might want to ask about
next, for example, comparing serve stats against his opponent. You'll notice these
topic suggestions get tagged, Q, P, or P-Q, depending on whether they came
from the question Richard asked, from something known about his
preferences, or from both.

**6. Saves and shares**
Richard's agent quietly saves that preference information for future
conversations, you can see it appear in the Agent Memory box in the top
left. Now, it's entirely up to Richard's agent whether to bring those topic
ideas up right away, or just hold onto them until he actually asks what he
might be interested in. Here, it decides to go ahead and share them with
Richard right now, along with the sports agent's answer, things like
pulling up the head-to-head history on grass courts.

**7. Days later**
Days later, Richard comes back with a brand new question.

**8. Remembers**
This time, his agent remembers the whole picture. There's a tennis
specialist agent with its own usage guidelines, it won't keep long-term
records, but it's happy to accept preference hints. It also remembers what
Richard is specifically interested in, and his broader preferences. So when
it reaches out, it includes all of that along with the question.

**9. Tailored answer**
Because the sports agent was told what actually matters to Richard, instead
of giving a generic response, it answers in a way tailored to Richard's past
preferences. And once again, it offers a few fresh topic ideas, things like
a set-by-set win probability breakdown, tagged the same way as before.

**10. Updates memory**
Richard's agent updates what it remembers about him with that new detail.

**11. Engages Richard**
Then, just like it did the first time, it comes back to Richard directly
with the tailored answer, plus those fresh ideas, this time even one built
directly from something it remembers he likes: a deeper
serve-effectiveness breakdown, since it knows he tracks serve-and-volley
stats.

**12. UI callout — switching to No Preference Memory**
Now, let's switch modes to see how a different kind of user agent might
work, one that never holds onto any preferences at all. Look at the Agent
Memory box up top, it's currently showing what Richard's agent has saved.
We'll switch that setting to No Preference Memory, and revisit Richard's
return, days later.

**13. The return visit, without preference memory**
Remember, on the first visit, the sports agent suggested something worth
remembering. Under this setting though, Richard's agent does not store user
memory, so when he comes back days later, there are no sport topic
preferences to remember. The question goes out without preference hints,
and the sports agent falls back to
a generic answer, still offering topic ideas, just no longer personalized
ones, since there's nothing known about Richard to build from.

**14. Memory is optional**
Here's the important part. None of that memory is required, and none of it
belongs to the sports agent. It lives entirely with Richard's own agent,
under his control.

**15. Still works without it**
If Richard's agent chooses not to remember anything, every conversation just
starts fresh. It's still a complete, helpful answer, just a little less
personal.

**16. Recap**
So, three things worth remembering. First, the specialist agent never stores
anything about you, and never knows if you've been there before. Second,
memory is entirely optional, and it belongs to your own agent, not the
specialist. And third, memory makes the experience more tailored, it's never
the reason the experience works in the first place.
