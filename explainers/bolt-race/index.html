Bolt race

One prompt, three places to run NVIDIA Nemotron 3.5 Bolt E4B: in this browser, on your own computer, and in NVIDIA's cloud. Each lane shows time to first token, speed and total time.

In this browser not loaded

Runs on your GPU with WebGPU. First load downloads about 4.9 GB, then it is cached. Best in current Chrome on a Mac with 16 GB or more.

Your computer not set up

Run Bolt in Ollama or LM Studio. Ollama blocks web pages by default, so start it with OLLAMA_ORIGINS=https://richoncode.github.io ollama serve. LM Studio: turn on the server and CORS, URL http://localhost:1234/v1. Safari may block http://localhost from an https page; Chrome allows it.

NVIDIA cloud not set up

Browsers can't call NVIDIA's API directly, and the key must never be in a page. Deploy the small Cloudflare Worker with your key as a secret, then paste its URL here.
