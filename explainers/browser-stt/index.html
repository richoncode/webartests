RTF = total ÷ clip length (lower is faster; under 1 is faster than real time). First run of each engine also includes warm-up.

Whistle runs through the community cactus-needle package (v0.3.0), wrapping Cactus Needle. Whisper via transformers.js. Parakeet via parakeet.js.
