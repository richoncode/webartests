Spatial sources explorer — data feeds + cameras, no access token required

375 public sources in one table: 300 real-time data feeds and 75 camera networks — every one usable with no access token. Built to answer one question: where do live cameras and quality live position data overlap, so a mock (or a real deployment) can pair a view with the data that moves through it? Use the Area scorecard tab for the ranked answer, or filter this table by Region and Area to inspect an area yourself.

How to use: click a column header to sort. Each Source entry starts with a one-line plain-English description. Region is the broad bucket (country / continent / Global); Area is the local bucket (city, metro, or state) and its options narrow to the chosen Region — pick an Area to see its cameras and data feeds side by side. Cameras carry no parsed position interval, so a speed filter hides them unless the "Include cameras & event-driven" box is ticked.

Aligned columns, inset extras: both kinds of source share Type, Region, Area, Coverage, Category/Scene, Update/refresh, Access/endpoint, Spatial/pose detail, Verification and Audience. Fields that exist on only one side (provider, format, timezones for data; operator, stream type, overlay candidates for cameras) and all Observations sit in the Misc column as labelled inset cells.

Scorecard: Score /8 = live-stream cameras (2, or 1 for snapshot-only) + fastest data cadence in the area (≤5 s: 3 · ≤1 min: 2 · ≤5 min: 1) + breadth (≥5 data feeds: 1 · ≥3 camera networks: 1). Global and orbital sources are excluded from the scorecard — they belong to no single area. Suggestion: start from the top of the scorecard; an area only earns a high score when a viewable camera and fast position data genuinely coexist there.

Verification: A = measured live on 2026-10-31 · B = keyless tier / operator-documented · C = documented, not fetched that day. No-token does not mean no terms: check each provider's licence/attribution before commercial use. God's Eye View (bilawalsidhu/gods-eye-view, MIT) supplied the keyless tier for the data index; its yellow free-key tier is on the Excluded tab with the keyless alternative used instead.
