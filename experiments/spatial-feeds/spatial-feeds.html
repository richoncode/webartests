200 Public Real-Time Spatial Data Sources — No Access Token Required

Plus the 100-service push supplement (30 fast-paced positional). Strict rule: no API key, no signup, no personal token. Sampled/compiled 2026-10-31. Verification: A = fetched live 2026-10-31, age measured · B = God's Eye View keyless tier / official no-auth registry · C = provider-documented, not individually fetched that day. Audience tags note who each source is for (Consumer, Construction, Emergency, Agriculture, Aviation, Maritime, Transport, Logistics, Energy, Environment, Government, Insurance, Media, OSINT & Defence, Research, Sports) — indicative, assigned by rule from category and content, not provider-stated. The Update interval (typical) column is derived from each row's Update rate text (mid-point of the stated range; continuous streams count as ~1 s; pushes with no fixed cadence are marked Event-driven) — use the two speed selects to filter by update-speed range: "at least every" sets the fastest cadence you want (e.g. at least every 1 s = only sources updating once a second or faster), "no faster than" sets the slowest. Published from the feeds-200.xlsx workbook.

How to use: click a column header to sort. Each Source entry starts with a one-line plain-English description, including how often positions update. Use Search for anything (provider, protocol, place). The Metro tab lists the sub-5-second sources for Portland, the SF Bay Area, San Diego and Los Angeles, including the sub-second waveform layer and its access caveats. Use the category switch for Data feeds vs Camera feeds (75 camera networks), and the Region filter to narrow either category to one area — a city, state, country, or Global — to see the cameras and data that overlap in one place. Endpoints that start with http(s) are clickable; TCP/MQTT/ZeroMQ endpoints are shown as host/topic text — copy them into your client. Slower-than-hourly rows are flagged in Observations. No-token does not mean no terms: check each provider's licence/attribution before commercial use. God's Eye View (bilawalsidhu/gods-eye-view, MIT) supplied the keyless tier; its yellow free-key tier (AISStream, NASA FIRMS, TomTom) is on the Excluded tab with the keyless alternative used instead.
