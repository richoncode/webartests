Project Vision

Lumina is a platform-agnostic, web-based alternative to the visionOS Photos ecosystem. Using WebXR, Three.js, and Monocular Depth Estimation, we democratize spatial media across all immersive hardware.

In Development Desktop Preview
WebXR not supported in your browser. Use an XR-compatible browser (e.g., Meta Quest or Vision Pro) to experience the gallery.

Orchestration Roadmap

PHASE 1

Foundation: Three.js r168 WebXR pipeline with zero foveation for edge-to-edge clarity.

PHASE 2

Volumetric: DepthAnything V3 integration for 2D to 3D image reconstruction.

PHASE 3

Interaction: Skeletal hand tracking and pinch-gestures via WebXR Hand Input API.

PHASE 4

Immersion: GLSL Feathered Edge shaders and environmental opacity controls.
