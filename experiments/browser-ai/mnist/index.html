What this page does

Where it runsEntirely in your browser. Nothing is uploaded. Training, inference, and storage stay on this device.
LibraryTensorFlow.js 4.22.0 from jsDelivr. No npm install and no build step.
BackendsAuto tries WebGPU (when navigator.gpu returns an adapter), then WASM, then WebGL, then CPU. WASM loads the SIMD binary when the browser accepts it. The banner names the backend TensorFlow.js actually started.
DataMNIST via the public TensorFlow.js sprite and label file (storage.googleapis.com/learnjs-data/model-builder/). The page keeps the first 12,000 training digits: 10,000 to train, 2,000 to validate. After the first download they live in IndexedDB (browser-ai / mnist-sprite-12k-v1).
ModelsTiny MLP: flatten, 64 ReLU, 10-way softmax. Small CNN: 3×3 conv (8), max-pool, 3×3 conv (16), max-pool, softmax. Optimizer is Adam. Loss is categorical cross-entropy. Pixels are scaled to 0–1.
DrawWhite strokes on black. The ink box is scaled to 20px and shifted so its center of mass sits in the middle of a 28×28 frame, then scored with softmax.
StorageBest validation checkpoint at indexeddb://browser-ai-mnist. Run metadata is appended to localStorage['browser-ai.runs'] for the hub Runs tab.
CaveatA few epochs on 10,000 digits is a demo, not a leaderboard run. WebGPU needs localhost or HTTPS. If it fails, the picker falls back and the banner says which backend took the job.
