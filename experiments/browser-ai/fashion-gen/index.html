What this page does

Where it runsEntirely in your browser. Nothing is uploaded. Training, sampling, and storage stay on this device.
LibraryTensorFlow.js 4.22.0 from jsDelivr, same scripts as the MNIST demo. No npm install and no build step.
BackendsAuto tries WebGPU (when navigator.gpu returns an adapter), then WASM, then WebGL, then CPU. The model is dense, so WASM can train it. The banner names the backend TensorFlow.js actually started.
DataFashion-MNIST (Zalando): 28×28 grayscale clothing — T-shirt/top, trouser, pullover, dress, coat, sandal, shirt, sneaker, bag, ankle boot. The page fetches the official 10,000-image test split as gzip IDX from jsDelivr, with GitHub raw as a fallback, then caches it in IndexedDB (browser-ai / fashion-mnist-10k-v1). Training uses 4,000 images and validation 1,000, from a fixed shuffle. The 60,000-image training file is left on the server so the first visit stays small.
ModelConditional VAE. Encoder: pixels concatenated with a 10-way class one-hot, 64 ReLU, then 8-d mean and log-variance. Decoder: latent code concatenated with the same one-hot, 64 ReLU, then 784 sigmoid pixels. About 104k parameters. Loss is Bernoulli reconstruction (binary cross-entropy, summed over pixels) plus β times KL to the unit normal. β is 0.25 for a one-epoch run and otherwise moves from 0.05 to 1. Optimizer is Adam.
SamplesGenerate draws z from the unit normal and decodes it with the chosen class. Class means decode the zero vector once per class. Latent walk blends two prior samples in eight steps. Press Generate again for a new draw.
PerfOne epoch, 256 images, batch 32, Adam at 0.001, then 32 generated images timed after a 4-image warmup. WebGPU, WASM, WebGL, and CPU run only when this browser has them. Results land in localStorage['browser-ai.fashion-perf']. These runs do not replace the saved checkpoint.
StorageBest validation checkpoint at indexeddb://browser-ai-fashion-cvae-h64-z8-enc and indexeddb://browser-ai-fashion-cvae-h64-z8-dec. Run metadata is appended to localStorage['browser-ai.runs'] for the lab hub.
CaveatA few epochs on 4,000 images produces soft, class-tinted garments. It will not look like a catalog photo. WebGPU needs localhost or HTTPS. If a backend fails to start, Auto falls forward and the banner says which one took the job.
