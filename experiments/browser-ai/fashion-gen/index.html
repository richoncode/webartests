What this page does

Where it runsEntirely in your browser. Nothing is uploaded. Training, sampling, and storage stay on this device.
LibraryTensorFlow.js 4.22.0 from jsDelivr, same scripts as the MNIST demo. No npm install and no build step.
BackendsAuto tries WebGPU (when navigator.gpu returns an adapter), then WASM, then WebGL, then CPU. The model is dense, so WASM can train it. The banner names the backend TensorFlow.js actually started.
DataFashion-MNIST (Zalando): 28×28 grayscale clothing — T-shirt/top, trouser, pullover, dress, coat, sandal, shirt, sneaker, bag, ankle boot, in that official order. The page fetches the official 10,000-image test split as gzip IDX from jsDelivr, with GitHub raw as a fallback, then caches it in IndexedDB (browser-ai / fashion-mnist-10k-v1). Training uses 9,000 images and validation 1,000, a fixed shuffle of the whole pool. The 60,000-image training file is left on the server so the first visit stays small.
ModelConditional VAE, dense only, so WASM can train it. The class one-hot is projected to a 16-d embedding and concatenated into both hidden layers and the pixel logits. A zero-initialized template maps the one-hot straight onto those logits, so the class has a path that does not depend on z. Encoder: 784 pixels plus the embedding, two 128-unit ReLU layers, then 16-d mean and log-variance. Decoder: z plus the embedding, two 128-unit ReLU layers, then 784 sigmoid pixels. About 270k parameters. Loss is Bernoulli reconstruction (binary cross-entropy, summed over pixels) plus β times KL to the unit normal. β is 0.25 for a one-epoch run and otherwise moves from 0.05 to 1. Optimizer is Adam. Captions are this conditioning input, not a classifier score.
SamplesThe class menu opens on Trouser. Generate draws z from the unit normal and decodes it conditioned on the chosen class. The real-vs-generated strip places two cached Fashion-MNIST images of that class beside the samples, with matching captions. A finished training run fills that strip for every class (two real, two generated) and the class means, instead of a random mix. Class means decode the zero vector once per class. Latent walk blends two prior samples in eight steps. The status line names the conditioned class. Press Generate again for a new draw.
PerfOne epoch, 256 images, batch 32, Adam at 0.001, then 32 generated images timed after a 4-image warmup. WebGPU, WASM, WebGL, and CPU run only when this browser has them. Results land in localStorage['browser-ai.fashion-perf']. These runs do not replace the saved checkpoint.
StorageBest validation checkpoint at indexeddb://browser-ai-fashion-cvae-e16-h128-z16-enc and indexeddb://browser-ai-fashion-cvae-e16-h128-z16-dec. Older tiny checkpoints (h64-z8) are not loaded. Run metadata is appended to localStorage['browser-ai.runs'] for the lab hub.
CaveatA few epochs still look soft next to the real tiles. Trousers, sneakers, and bags should read as those classes sooner than shirts, coats, and pullovers, which share a silhouette. It will not look like a catalog photo. The caption is the class the decoder was given. WebGPU needs localhost or HTTPS. If a backend fails to start, Auto falls forward and the banner says which one took the job.
