Phase 1 will pick one stack — TensorFlow.js — and walk this order. The banner is the check those pages already share.

Preferred

WebGPU

Chrome and Edge, in a secure context (localhost or HTTPS). Used when navigator.gpu returns an adapter. Fastest path for a tiny train loop, and the one the banner marks green.

Fallback

WASM, SIMD when present

Runs where WebGPU does not. SIMD is detected with a small WebAssembly.validate probe and shown as its own chip. Slower than the GPU, still entirely in the tab.

Last resort

WebGL, then CPU

WebGL2 (or WebGL 1) if WASM is missing. CPU is only the leftover when the page cannot see GPU or Wasm. The MNIST backend picker lists all four and stays disabled until training exists.
