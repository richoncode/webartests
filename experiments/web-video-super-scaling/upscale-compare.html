Filled means a small slice of the frame. Outlined means it only fits as a large slice, or as the main fullscreen pass. No tag means it does not fit. QC XR is Snapdragon XR2 Gen 2 / XR2+ Gen 2 class (Quest 3, Galaxy XR): one eye, one 2× pass into the brief’s 2.2K×2.4K render target at 90 Hz. QC AR is Snapdragon AR1 / AR1+ / AR2 glasses: 1280×1280 at 60 Hz, sparse GPU, SoC power under about 1 W. Original is the reference and has no tag. 4× is two passes (~1.25× the MACs) and does not retag. Qualcomm does not publish TOPS or bandwidth for these parts, and these nets are not Hexagon QNN graphs.

Clip. Top eye of the fixed red/green football stereo feed already used by this folder (streams.quintar.ai/kyle/20251207-red-green/8Mbps). testdata/ only had stills, and that broadcast is HEVC 3840×4320, which desktop Chrome often will not decode. This page plays a 6s H.264 1920×1080 excerpt of the top eye, testdata/red-green-top-eye.mp4. Tabs switch the five upscaled panels. The original, magnifier, downscale factor, and playback stay put. Browser universal is the classical set plus Anime4K CNN-S. Shader sharpeners are FSR 1 (EASU+RCAS), NVIDIA Image Scaling, CAS on bilinear, Hyllian xBR-lv2, and Lanczos plus an unsharp mask. Neural (WebGPU) is Anime4K CNN-S, M, L, GAN-S, and CNN-VL, each an x2 network run twice at 4×. Neural custom ships five webartests-sr-v1 nets (see upscale-models/). Football ESPCN-tiny is the short luma net trained on this clip. Football wide is a deeper luma ESPCN trained longer on later frames of the same broadcast; this 6s clip is held out. Football RGB predicts an RGB residual so jersey colors and field lines are not left to bilinear chroma. Football temporal reads the current and previous luma, with no motion warp. A repeated timestamp keeps the same previous frame. Football distill is a smaller student of Anime4K CNN-M. Real-ESRGAN was not run; the training script says why. Drop a JSON file on a panel to replace that preset. Older espcn-y files still load. espcn-rgb and espcn-y2 are the added arch values. Sharp lines (exploring) keeps that wide net as the baseline and does not replace it. Wide + RCAS and Sharp + RCAS run FSR 1 RCAS on the network output. The RCAS slider is in stops: 0 is the strongest, 2 is the mildest, and 0.20 matches the FSR 1 panel. The other panels ignore it. Sharp edges is the same 1-16-16-16-4 luma net trained with Sobel-weighted error and crops drawn from high-gradient blocks on later stream frames. This clip is held out. Sharp perceptual continues those weights with a Laplacian term, a Sobel-matching term, and a 4→8→8→1 patch discriminator. Real-ESRGAN and VGG were not run; there is no PyTorch on the training machine. PSNR and SSIM are luma versus the original; SSIM uses 8×8 boxes. Edge is luma PSNR on pixels whose reference Sobel magnitude is at least 200, so a blurry line is not rewarded the way full-frame PSNR rewards it. The hash remembers the tab. Hover a panel title for a short description of that method. The headset tags are an estimate from public Qualcomm product briefs and each method’s tap or MAC count, not a run on a Quest or a pair of glasses.
