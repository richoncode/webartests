Locked decisions

Fog of warAge of Empires style, three states: black = never scouted; grey = explored (terrain remembered, units hidden or shown only as stale last-seen marks); clear = current sensor vision. Twist: a drone that loses its link stops revealing, so its area falls back to grey. Not Homeworld-style sensor bubbles. (This replaces the coverage-mask fog in the v2/v3 concept doc.)
Map and timeOpen, continuous top-down map. Real time with pause. No grid.
EconomyLight: a per-mission supply budget only. No base or civ building.
CoreAssign roles and behaviors (role cards + if-then rules); air and ground drone types; tech unlocks earned through objectives; jamming and link loss as a core mechanic.
Scale and fictionCampaign scale follows the published Russia–Ukraine drone-count curve (pacing only). Fictional factions.

A. Real Russia–Ukraine war maps (rejected)Instant authenticity; terrain is "free".Tone and reputation risk (gamifying an ongoing war with real casualties); pulls toward real factions, which we've ruled out; real geography limits mission design.

Fictional / procedural maps from real terrain archetypes (chosen for the campaign; river lines, tree belts, dense villages, open farmland)Full design freedom; each map can be tuned for a lesson (e.g. a river forcing relays); replayable via seeds; no real-place baggage.Needs a generator and art pass; risks feeling generic if archetypes are thin.
C. Maps built from real elevation and land-cover data of a neutral region (chosen for prototypes; like the vignette's San Martin Foothills basemap)Believable terrain and real line-of-sight for little art cost; neutral place avoids the war framing; reuses the vignette's basemap work.Less control over mission layout; real-world tiles carry licensing and attribution limits; fixed maps reduce replay unless missions vary.

Decision: Option C for prototypes (real elevation and land cover of a neutral region, e.g. the San Martin foothills). Option B for the campaign (fictional maps built from real terrain archetypes). Option A (real war maps) is rejected. Reasons: no tone or reputation risk, fictional factions stay fictional, C reuses the vignette's basemap now, and B gives full design freedom later.

Training Exercise 1 prototype spec (Step 1; built: play it)

  • Stack: Browser, reusing the vignette stack: Leaflet 1.9.4 with a 2D canvas overlay, and the link-state code (ok / degraded / lost) in richoncode/webartests → experiments/dronscape/. Reference only; no repo changes until you say go.
  • Map: One map, about 3×3 km, using Option C: the existing San Martin Foothills basemap (already wired). The fog layer is map-agnostic, so it carries over to Option B campaign maps later.
  • Units: 3 scout drones from one launch point. Click to select, click to move, shift-click to queue waypoints, a return button. Battery of about 6 min, so routes matter. Space bar pauses; orders work while paused.
  • Fog: A grid of about 20 m cells, each black, grey, or clear, drawn on the canvas (black opaque, grey dimmed, clear transparent). A linked drone clears cells within its sensor radius (about 300 m); cells it leaves drop to grey. Minimal twist: past a link-range ring around the launch point, a drone keeps its last order but stops revealing. Terrain line of sight is deferred.
  • Enemies: 6–8 hidden objects, seeded randomly per run: static sites plus 2 patrolling vehicles. They're visible only in clear cells. A patrol that leaves vision leaves a faded last-seen mark with its age.
  • Timer and score: 8-minute mission. +100 per object found, a time bonus, a penalty for drones lost to empty batteries. The end screen shows the score, seed, and a Replay button.
  • Time box: One cloud-agent PR, about 2 working days, plus a half-day playtest.
  • Measure: A local telemetry log with JSON export: Replay clicks, run length, orders per minute, pauses, % of map explored, time to first and to each find, drones lost. Plus 3 post-play questions: Was scouting fun? Did the grey memory help? What did you want to do that you couldn't?
  • Revision 1b (after Richard's first play): Framed as Training Exercise 1, with exercises defined as data so Exercises 2–6 can be added (shown as locked). Route changes can be undone (Ctrl+Z / Backspace / button, plus a 'Route replaced' toast with Undo). 'Remove last waypoint' added. Per-scout and default 'Finish at home' adds a return leg, and the battery warning counts it. One contact is always 500–800 m from launch, for a faster first find.
