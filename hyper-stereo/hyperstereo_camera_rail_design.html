Motorized Hyperstereo Camera Rail

1. Design Goals

Fast temporary installation

Two people should be able to unload, mount, level, align, cable, and validate the rig in approximately 30 minutes, without permanent venue modification.

Venue adaptability

Adapt to railings, lighting stands, scaffold, walls, balcony fronts, or other event constraints while achieving the best practical hyperstereo geometry within set-day time limits.

Arbitrary support positions

Allow both temporary support interfaces to clamp at any sufficiently separated positions along the main beam rather than forcing attachment near fixed endpoints.

Baseline azimuth alignment

Allow either support to use an adjustable extension arm so the optical baseline can be rotated parallel to the intended zero-parallax plane even when venue attachment points are offset.

Repeatable stereo geometry

Provide repeatable camera spacing, yaw, roll, and height, with measured settings recorded as capture metadata.

Safe experimental flexibility

Support manual, parallel, converged, and baseline-sweep modes while preserving limits, E-stop behavior, secondary retention, and conservative wind restrictions.

Primary design principle: the venue determines where supports can attach; the support interfaces and optional outriggers then adapt those points to the beam, rather than forcing the beam geometry to follow the venue.

2. System Summary

A 40 x 80 mm T-slot extrusion acts as the common optical and structural datum. Two camera carriages translate along the beam, and each carries a geared yaw stage. Two independent support saddles slide anywhere along the beam. Either saddle may connect directly to a stand or through an adjustable outrigger arm.

3. Adaptive Temporary Support System

The support subsystem is revised so neither support has a fixed beam location. Each uses a sliding beam saddle that locks into the lower and rear T-slots with at least four captured T-nuts. The saddle may be positioned anywhere that leaves safe clearance for camera travel and provides adequate support separation.

3.1 Sliding beam saddle

  • 6-10 mm aluminum plate wrapping the lower beam corners.
  • Four or six M8 roll-in T-nuts distributed across two slots.
  • Tool-less cam handles or captive star knobs for fast field positioning.
  • Engraved beam scale and saddle index mark for recording positions.
  • Anti-drop keeper so the saddle remains captured when loosened.

3.2 Optional alignment outrigger

An outrigger is a rigid telescoping or slotted arm between the venue attachment and beam saddle. It provides approximately 150-600 mm lateral offset and +/-20 degrees of plan-view adjustment. One or both supports may use outriggers. A spherical rod end or clevis at one end prevents assembly stress, while a serrated rosette or bolted friction joint locks azimuth.

Structural caution: an outrigger creates bending moment at the stand and beam saddle. Rate the arm, joint, stand, ballast, and venue clamp for the worst eccentric load. Long outriggers should use a triangular brace or guy line rather than a single unsupported arm.

3.3 Integrated level and alignment aids

Main-beam level

Install a protected machinist-style spirit vial parallel to the beam's camera travel axis. Add a second short cross-axis vial to reveal beam roll. A small digital inclinometer or MEMS IMU may be added for logged measurements.

Zero-parallax-plane alignment

Fit two removable sighting pins or laser modules along the beam normal. Rotate the beam in plan view until its long axis is parallel to the selected zero-parallax plane, then lock both outrigger joints.

4. Stereo and Vergence Geometry

Parallel capture remains the calibration reference because toe-in introduces keystone and vertical disparity. Physical vergence is retained as an experimental mode. Baseline orientation in plan view should be parallel to the desired zero-parallax plane; the adaptive supports and outriggers are specifically intended to make that possible despite imperfect venue attachment geometry.

5. Mechanical Design

5.1 Main beam

Use one 40 x 80 mm 6063-T6 T-slot extrusion with the 80 mm dimension vertical. Add end caps, physical carriage stops, a beam-center datum, engraved distance marks, and a recessed dual-axis bubble level near the center where it can be read from behind the rig.

5.2 Camera translation

Each camera rides on a 6 mm or thicker aluminum carriage plate using an MGN15/MGN20-class guide or a preloaded dual V-wheel system. Independent GT2 or HTD belt drives preserve a fixed beam midpoint when the cameras move symmetrically.

5.3 Yaw stages

Each camera sits on a low-backlash bearing with approximately 5:1 reduction. An Arca fore/aft rail allows the yaw axis to be placed near the lens entrance pupil. Include a mechanical zero detent for quick parallel setup even if electronics are unavailable.

8. ESP32 Control Software

The reference firmware exposes HTTP endpoints for homing, commanded baseline and convergence, status, and stop. It assumes step/dir drivers and should be extended with outer limits, support-clearance zones, watchdog handling, and persistent calibration before field deployment.

#include <Arduino.h>
#include <WiFi.h>
#include <WebServer.h>
#include <AccelStepper.h>

static const char* WIFI_SSID = "HyperStereoRail";
static const char* WIFI_PASS = "change-this-password";
WebServer server(80);

constexpr int LBASE_STEP=4,  LBASE_DIR=5,  LBASE_HOME=6;
constexpr int RBASE_STEP=7,  RBASE_DIR=8,  RBASE_HOME=9;
constexpr int LPAN_STEP=10,   LPAN_DIR=11,  LPAN_HOME=12;
constexpr int RPAN_STEP=13,   RPAN_DIR=14,  RPAN_HOME=15;
constexpr int ESTOP_PIN=16, DRIVER_ENABLE=17;

AccelStepper leftBase (AccelStepper::DRIVER, LBASE_STEP, LBASE_DIR);
AccelStepper rightBase(AccelStepper::DRIVER, RBASE_STEP, RBASE_DIR);
AccelStepper leftPan  (AccelStepper::DRIVER, LPAN_STEP, LPAN_DIR);
AccelStepper rightPan (AccelStepper::DRIVER, RPAN_STEP, RPAN_DIR);

constexpr float BEAM_USABLE_MM = 2650.0f;
constexpr float MIN_BASELINE_MM = 350.0f;
constexpr float MAX_BASELINE_MM = 2500.0f;
constexpr float MIN_CONVERGENCE_MM = 3000.0f;
constexpr float MAX_YAW_DEG = 15.0f;
constexpr float BASE_STEPS_PER_MM = (200.0f * 16.0f) / 40.0f;
constexpr float PAN_STEPS_PER_DEG = (200.0f * 16.0f * 5.0f) / 360.0f;

bool homed = false;
String faultText;

bool estopHealthy() { return digitalRead(ESTOP_PIN) == HIGH; }
void drivers(bool on) { digitalWrite(DRIVER_ENABLE, on ? LOW : HIGH); }
long mmToBaseSteps(float mm) { return lroundf(mm * BASE_STEPS_PER_MM); }
long degToPanSteps(float deg) { return lroundf(deg * PAN_STEPS_PER_DEG); }

void stopAll(const String& why) {
  leftBase.stop(); rightBase.stop(); leftPan.stop(); rightPan.stop();
  drivers(false); faultText = why;
}

bool runUntilIdle(uint32_t timeoutMs) {
  const uint32_t started = millis();
  while (leftBase.distanceToGo() || rightBase.distanceToGo() ||
         leftPan.distanceToGo() || rightPan.distanceToGo()) {
    if (!estopHealthy()) { stopAll("E-stop opened"); return false; }
    leftBase.run(); rightBase.run(); leftPan.run(); rightPan.run();
    if (millis() - started > timeoutMs) {
      stopAll("Motion timeout"); return false;
    }
    delay(0);
  }
  return true;
}

bool homeOne(AccelStepper& axis, int switchPin, int direction,
             float speedStepsPerSec, long backoffSteps) {
  axis.setMaxSpeed(speedStepsPerSec);
  axis.setSpeed(direction * speedStepsPerSec);
  uint32_t started = millis();
  while (digitalRead(switchPin) == HIGH) {
    if (!estopHealthy()) return false;
    axis.runSpeed();
    if (millis() - started > 30000) return false;
    delay(0);
  }
  axis.setCurrentPosition(0);
  axis.move(-direction * backoffSteps);
  return runUntilIdle(5000);
}

bool homeAll() {
  faultText = "";
  if (!estopHealthy()) { faultText = "E-stop is open"; return false; }
  drivers(true);
  if (!homeOne(leftBase,  LBASE_HOME, -1, 800, mmToBaseSteps(10))) return false;
  if (!homeOne(rightBase, RBASE_HOME, +1, 800, mmToBaseSteps(10))) return false;
  if (!homeOne(leftPan,   LPAN_HOME,  -1, 400, degToPanSteps(2))) return false;
  if (!homeOne(rightPan,  RPAN_HOME,  +1, 400, degToPanSteps(2))) return false;
  leftBase.setCurrentPosition(mmToBaseSteps(-BEAM_USABLE_MM / 2.0f));
  rightBase.setCurrentPosition(mmToBaseSteps(+BEAM_USABLE_MM / 2.0f));
  leftPan.setCurrentPosition(0);
  rightPan.setCurrentPosition(0);
  homed = true;
  return true;
}

bool commandRig(float baselineMm, float convergenceMm) {
  if (!homed) { faultText = "Rig is not homed"; return false; }
  if (!estopHealthy()) { stopAll("E-stop opened"); return false; }
  baselineMm = constrain(baselineMm, MIN_BASELINE_MM, MAX_BASELINE_MM);
  const float leftX  = -baselineMm / 2.0f;
  const float rightX = +baselineMm / 2.0f;
  float yawDeg = 0.0f;
  if (convergenceMm > 0.0f) {
    convergenceMm = max(convergenceMm, MIN_CONVERGENCE_MM);
    yawDeg = degrees(atanf(baselineMm / (2.0f * convergenceMm)));
    yawDeg = constrain(yawDeg, 0.0f, MAX_YAW_DEG);
  }
  drivers(true);
  leftBase.moveTo(mmToBaseSteps(leftX));
  rightBase.moveTo(mmToBaseSteps(rightX));
  leftPan.moveTo(degToPanSteps(+yawDeg));
  rightPan.moveTo(degToPanSteps(-yawDeg));
  return true;
}

String statusJson() {
  String s = "{\"homed\":" + String(homed ? "true" : "false");
  s += ",\"estop\":" + String(estopHealthy() ? "false" : "true");
  s += ",\"left_mm\":" + String(leftBase.currentPosition()/BASE_STEPS_PER_MM, 2);
  s += ",\"right_mm\":" + String(rightBase.currentPosition()/BASE_STEPS_PER_MM, 2);
  s += ",\"left_yaw_deg\":" + String(leftPan.currentPosition()/PAN_STEPS_PER_DEG, 3);
  s += ",\"right_yaw_deg\":" + String(rightPan.currentPosition()/PAN_STEPS_PER_DEG, 3);
  s += ",\"fault\":\"" + faultText + "\"}";
  return s;
}

void setupHttp() {
  server.on("/status", HTTP_GET, [](){ server.send(200,"application/json",statusJson()); });
  server.on("/home", HTTP_POST, [](){
    bool ok=homeAll(); server.send(ok?200:500,"application/json",statusJson());
  });
  server.on("/move", HTTP_POST, [](){
    if (!server.hasArg("baseline") || !server.hasArg("distance")) {
      server.send(400,"text/plain","baseline and distance are required"); return;
    }
    bool ok=commandRig(server.arg("baseline").toFloat(),
                       server.arg("distance").toFloat());
    server.send(ok?202:409,"application/json",statusJson());
  });
  server.on("/stop", HTTP_POST, [](){
    stopAll("Operator stop"); server.send(200,"application/json",statusJson());
  });
  server.begin();
}

void setup() {
  pinMode(LBASE_HOME,INPUT_PULLUP); pinMode(RBASE_HOME,INPUT_PULLUP);
  pinMode(LPAN_HOME,INPUT_PULLUP);  pinMode(RPAN_HOME,INPUT_PULLUP);
  pinMode(ESTOP_PIN,INPUT_PULLUP);  pinMode(DRIVER_ENABLE,OUTPUT);
  drivers(false);
  for (AccelStepper* a : {&leftBase,&rightBase,&leftPan,&rightPan}) {
    a->setMaxSpeed(4000); a->setAcceleration(2500);
  }
  leftPan.setMaxSpeed(1200); rightPan.setMaxSpeed(1200);
  leftPan.setAcceleration(800); rightPan.setAcceleration(800);
  WiFi.mode(WIFI_AP);
  WiFi.softAP(WIFI_SSID,WIFI_PASS);
  setupHttp();
}

void loop() {
  server.handleClient();
  if (!estopHealthy()) { stopAll("E-stop opened"); delay(20); return; }
  leftBase.run(); rightBase.run(); leftPan.run(); rightPan.run();
}

9. Event-Day Installation Workflow

  1. Survey: identify two safe attachment regions with sufficient separation, structural rating, camera sight lines, and operator access.
  2. Choose saddle positions: place supports as far apart as practical while keeping them outside the expected camera travel zones.
  3. Select direct or outrigger mounting: use direct adapters when venue points already lie near the desired baseline; install one or two outriggers when lateral correction is required.
  4. Raise and retain: mount the beam, install safety cables, ballast/guy supports, and only then release handling support.
  5. Set level: adjust support height using the longitudinal vial, then remove roll using the cross-axis vial.
  6. Align baseline azimuth: sight the selected zero-parallax plane and rotate/extend outriggers until the beam is parallel to it.
  7. Lock and witness-mark: torque all saddle and outrigger fasteners and apply visual witness marks.
  8. Home and clearance-test: home at reduced speed, verify support exclusion zones, and run a slow full-range test without cameras if practical.
  9. Install cameras and calibrate: measure entrance-pupil baseline, set parallel yaw, verify roll, focus, synchronization, and stereo calibration.
  10. Record setup metadata: saddle positions, outrigger lengths, beam level, baseline azimuth, camera baseline, yaw, lens settings, and calibration file identifier.
